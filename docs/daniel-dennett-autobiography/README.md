# 我一直在想：丹尼尔·丹尼特唯一自传

[美] 丹尼尔·丹尼特

107个笔记

**推荐序一 丹尼尔·丹尼特：跨界思想的摆渡人**

* “我们不是宇宙的旁观者，而是自我叙事的创作者——这份创造的自由，才是进化馈赠的最珍贵礼物。”
* 他用哲学写作验证的不仅是思维的完整性，更是理性精神对抗生命无常的永恒力量。

**推荐序二 刚中带柔的丹尼特**

* 为什么在当今科学昌明、技术发达的时代，还要关心哲学？ 因为有些重大问题，科学还暂时不能、也许永远都无法给出答案，而我们迫切地想要知道答案。哲学的作用是让我们不至于完全束手无策：只要你能清晰思考，你就能得到比不思考好得多的答案。
* 丹尼特不但认为意识不神秘，而且认为“有意识”也不是什么了不起的特权。他说：所谓我们认为一个东西有意识，只不过是一种方便的立场而已。丹尼特把我们对物体的解释，按照你如何预测它的行为，分为三个层级。 第一级是物理立场(physical stance)：我们只当这东西是个自然的存在，也许考虑它的物质成分和运行规律，但仅此而已。比如你对一块石头、对太阳系中的行星，就是物理立场——你可以完全根据自然规律预测它们的运动，你不认为它们是活的。 第二级是设计立场(design stance)：我们当某个东西有特定的功能，也许是专门设计出来的。比如汽车能开，菜刀能切菜。它们之所以是这个样子，是因为就是这样用的。 第三级是意向立场：我们对某个东西有自身的想法和目的，而不是只被外界束缚。比如我们对人类和至少某些动物就是采取意向立场。 那你说这些立场都是严格划分的吗？设计立场是因为那个东西一定是谁设计出来的，意向立场是因为这个东西一定是生物学意义上活的吗？不是！妙处就在于，这三个解释层级只是我们方便的分类而已，我们关心的只是立场对这个东西的行为的预测力。 比如说，一台计算机处于关机状态的时候，你只会用物理立场看它；它开机运行程序，你就会用设计立场看它；而当你跟它下棋的时候，你就可能用意向立场了，说电脑“想要”在这里吃你一个子……而自始至终那都只是一台计算机，并没有发生什么神奇的飞跃，只是你根据情境采取了不同的立场。 所以丹尼特说，所谓这个东西有心智，也只不过是一种意向立场。 这样一来，心智就不是二元论意义上的本质特征，而只是一种方便的、主观的描述而已。只要一个系统足够复杂，值得用意向立场刻画，我们就可以说它“有心智”。人的心智跟计算机的心智没有绝对本质的区别。
* 丹尼特巧妙地重新定义了自由意志。他提出，只要你能在一定程度上做出选择，把原来不可避免的事情变成可避免，你就多了一分自由意志。 相对的自由。
* 我们很庆幸地拥有“自我”——能跳舞，能创造文化，能使用语言，还能产生宗教。这些事情并不能简单地用一句“都是原子组成的”来概括，它们跟原子之间隔了很多层，但是丹尼特说，这些的确是可以解释的。 丹尼特拥有两件最锋利的思想武器：一个是进化论，一个是计算机。达尔文进化论展现了纯粹机械的过程如何能塑造出复杂生物和高级智能；计算机则给思想家提供了类比，让我们猜测和理解大脑如何处理信息。在我看来，这两件武器是当代思想者必备的功夫。

**推荐序三 思考，在人群中**

* 可塑的心智并不是孤立的，而是始终处于种类杂多的观念环境之中。一个人心智中的种种思想观念也不全是无中生有般地从他的内心浮现的，而是绝大多数都来自他周遭的可得(available)观念环境。唯有在充分地获得了足够多、足够前沿的思想的基础上，一个人的心智才能够做出真正有价值的观念探索和理论创造。
* 与其他生物比起来，人类的特别之处在于，自主的人能够基于一种未来自我愿景，主动地趋近、采纳某些种类的观念，最终自己把自己的心智塑造成某种模样
* 哲学家的炼成过程绝不是如大众以为的那样在高山之巅孤独沉思的过程，而是一个主动改变自身观念小环境，主动建构自己心智的过程。
* 丹尼特承认，与所有人一样，他也有可能会出错。事实上，在与反对者的交流和争论中，丹尼特绝不是固执己见的人，他会扩展、修改甚至放弃原先的观点。但一个人千万不要因为这种可能性而踌躇不前。关键是开始想起来，写下来，让思想把你大脑中浮沉流逝的念头对象化为确定的文字，这样你才能修订、改善它们。把你的文字公布出来，融入人群的观念环境，在与他人的交流中不断调整它们。在此，丹尼特的“多重草稿”不仅是他意识理论的模型，也是他思考和写作过程的模型。

**推荐序五 太平年代的造光人**

* 丹尼特的家庭生活也很美满。他20岁时就与妻子苏珊结婚，两人琴瑟和鸣，携手走过了60多年的漫漫人生路。
* 我有一位朋友，也是武汉大学哲学系的老师，就说思想家真的需要这种平淡而顺畅的人生，这在很大程度上可以保证他们充分发挥自己的专业能力，为人类产出新颖而深刻的洞见。

**推荐序六 理解一切，感谢美好**

* 高中期间，他曾经因为质疑一位英文老师宣称“莎士比亚是有史以来最伟大的人”而被区别对待。他并没有屈服，继续在课堂上反对这类看起来很傻的言论，结果期末操行被评为F。他将其视为一种褒扬。中学毕业时，他所在中学当年有近1/5的学生申请去了哈佛大学，而他喜欢卫斯理大学，于是就去了卫斯理大学。大一时，读到哲学家蒯因的著作，认为蒯因错了，丹尼特干脆转学到哈佛大学跟蒯因当面辩论。在哈佛大学期末考试中，他多次因太执着于把问题解决掉，而不是把题目回答完，而得分不高。后经由蒯因的强力推荐，丹尼特到牛津大学跟着赖尔攻读哲学博士学位，他更彻底迷上了用科学方法解析哲学问题：意识、自由意志、宗教……这些曾被视为不可彻底言说的主题，在他眼里都是等待拆解的机械钟表。一切都是可以理解的，直到精疲力竭。1965年获得哲学博士学位后，丹尼特先到加州大学尔湾分校任教，后于1971年加入塔夫茨大学，创立著名的认知研究中心，在此扎根近半个世纪。他像个思想工程师，把哲学、神经科学、计算机科学、进化论的学者和学说凝聚到一起，盖起以意识研究为基础的大厦。 丹尼特的研究，本质上是一场祛魅运动。兹略举数例。 关于意识主体和意识的内容，他否认有一个“我”，否认“我”有一些不为外人所知的体验，比如感受质。大致来说，感受质指人们具有意识经验时的主观内容。比如，看到红色时心中感觉到的红。许多哲学家都认为，感受质是意识最不可还原的部分。
* 丹尼特认为，对红色的感觉没有什么特别的，神经科学显示，色盲者、鸟类、机器人对红色会做出不同处理，我们的主观体验不过是大脑叙事的产物。而根据他提出的多重草稿模型：大脑里没有中央决策者，只有无数并行的信息处理流，所谓统一、连续的“我”，不过是大脑讲给自己听的一个故事。“我”是讲故事讲出来的，而大多数人却以为是“我”在讲故事。
* 关于意识到的自由，或者所谓的自由意志，丹尼特站在进化论一边，否认自由具有那种能游离于因果链的神秘力量。他解释，即便世界是决定论的，人类的知识局限也让未来保持“优化的开放性”——你知道“按下按钮会爆炸”，所以选择不按，这就是自由，未来以某种投影的方式对现在造成影响。要是不考虑未来呢？那自然是过去影响了现在。
* 除了医学和科学，丹尼特也真诚地感谢世界上一切带来美好的事物，一曲音乐、一架钢琴、一捧清澈的水或是餐桌上美味的食物，这些看似习以为常的部分叠加起来就构成了美妙生活的整体。
* 探索事物的本质，从不需要跪拜神秘；恰恰相反，当理性的光照亮每一寸幽暗，那些答案将会清晰而动人。不过，他也非常真诚地提醒我们，无论认识多么深入，其实只是浅尝而已；在更大的世界里，我们的世界微不足道。

**前言 幸运的丹尼特**

* 我们最好承认，在某种程度上，学术是一项极其奢侈的事业，维持着成千上万的项目，这些项目可能永远不会以任何可预见的方式“自给自足”。我们千万不能让学术界变成另一个训练场，只培养不久的将来可能会用到的工作者。要允许百花齐放，然而也要记住，它们中的大多数都会凋谢…
* 与艾柯见面后，我发现他原来是一个令人愉悦的人，学识渊博得叫人难以置信，而且他在运用渊博的知识时很优雅，对他人的想法也非常感兴趣，能说会道，总能讲出很多有趣的故事和观察评论。无论话题是什么，他似乎都能立即抓住关键要素和问题所在，而且他经常在谈话中补充一些惊人的见解。

**23 《意识的解释》**

* “到达世界知识的边缘，寻找最复杂、最精密的头脑，把他们放在一个房间里，让他们互相答疑解惑”
* 假设你有一个关于实验的好主意，你尝试了一下，但结果并不像你所希望的那样。你该怎么做？把你所有的笔记和数据都塞进一个装着废弃想法的文件抽屉里吗？为什么不能这样做？因为你的失败或许和成功一样重要。
* 正如艺术哲学家阿瑟·丹托在一篇关于诺曼·罗克韦尔(Norman Rockwell)的文章中所说：“绘画不仅仅是画布上的事。它是画布和赏画者之间的事。”

**26 西蒙·派珀特与马文·明斯基**

* 正如明斯基后来所说：“如果这个理论再模糊一点，它就会被忽略，但如果它得到了更详细的描述，其他科学家可能就会‘检验’它，而不是贡献他们自己的想法。”
* 我的爱好是实践“人工制品诠释学”——对一件复杂的人工制品实施逆向工程，以弄清楚它的设计意图。

**27 《打破魔咒》**

* 观念就像病毒，它们有自己的适应性，一个观念即一个模因，可以在一个社会中像大流行病一样传播，而这些观念对采纳它的人而言不一定有益。许多关注宗教的作家认为，宗教的成功表明它提高了其信徒的适应性。例如，它有助于建立团队合作、忠诚和对同胞的爱，以及为一项事业献身的意愿。这无疑是故事的一部分，但必须在一个更清晰、科学的背景下理解：在适当的条件下，进化可以培养出非适应性习惯、幻觉，甚至是自我毁灭的表现。
* 如果我想阻止对某些话题的深入研究，我不会试图明确禁止这样的工作，或设置烦琐官僚的程序让获取数据的过程变得冗长，我只会雇用大量二流的人来从事这项工作，然后指望他们的存在把更敏锐和更有想象力的研究者赶走。

**28 与乔纳森·米勒和马修·赫尔利一起寻找搞笑骨头**

* 他们对问题案例所采取的广博且公平的立场是积极的：他们将自己的理论视为一个临时的中转站，并促进了对这些开放式问题的进一步实证研究。总的来说，这大概是学者应当有的正确态度。

**30 TED演讲**

* 恐慌是最大的敌人。处于恐慌中时，人们会做出愚蠢、疯狂的事情。

**33 哲学史与理查德·罗蒂**

* 哲学史在很大程度上就是错误史，这些错误都是聪明绝顶之人犯下的，非常具有诱惑性。如果你不了解这段历史，几乎肯定会犯同样的错误，因为它们依然非常具有诱惑性。
* 哲学不只是科学，尽管有些哲学家试图让它尽可能地变成科学；哲学也不只是诗歌。我最喜欢的关于哲学的定义由塞拉斯提出：“抽象地说，哲学的目标在于去理解最广泛意义上的事物如何在最广泛意义上相互关联。”
* 那些想要满足自己好奇心的人会发现，试图正式地、系统地把所有问题排列起来、逐一破解，注定会失败。这就是为什么哲学是一门艺术，是一种拓宽想象力的练习，这个过程要打破由大量一知半解的观念所设置的障碍。

**34 那些学术“霸凌者”与反传统者**

* 詹尼斯·乔普林(Janis Joplin)的《我和鲍比·麦吉》(Me and Bobby McGee)中有一句歌词：“自由只是‘没什么可失去的’的另一个说法。”
* 语言不可能通过交流的选择压力而进化，因为我们可以问人们他们感觉怎么样，但并不真的想知道答案。
* 我们都必须避免掉进“认真对待每个人”的陷阱，同时也要避免掉入一个元陷阱：认真对待我们所有的判断，并为其进行辩护。

**35 逆向工程，人们的思考工具**

* 侯世达建议我，面对任何思想实验，都应该“转动所有的旋钮”，以确保知道到底是什么让它起了作用。这真是他给我的最好的礼物。
* “只用双手，你做不了多少木工活；只用大脑，你也想不出多少问题。”
* 无论用哪种方法，我们都应该时常后退一步，看看进展如何，根据所需来调整方向。
* 生命带来了存在的理由和意义，在我们这个宇宙角落，只有人类拥有基于语言的思考工具可以弄清楚这一点。我们是这颗星球上唯一的推理者(reasoner)，即严格意义上的解释者(explainer)。数十亿年前，原因或者说理由(reason)就先于推理者存在，就像数字先于数学家存在一样。
* 每一个生物都因为各种理由而变成现在这样，但只有我们人类才表征理由。
* 树木能相当出色地应对很多情况，却没有一丝理解力；兔子、狐狸和大象也是如此，它们做了许多明智的事情，却不需要知道为什么这样做是明智的，或者什么时候该去做。我们人类提出了“为什么”，并且能评估各种答案，正是这些能力让我们有别于自然界的其他部分，而不是某种明显很神奇的灵魂在理解、感受、爱和恐惧。
* 用户错觉可以被更好地视为一个有用的抽象概念：叙事重心。我们互相提问，其他物种的成员都做不到这点。我们给出的答案并非万无一失，也不是通过内省就可以完全获得，却无限接近于任何人所能达到的我们“真正的意思”。蒯因坚持认为，激进的翻译无法确保找到唯一正确的解释，这是正确的。米利肯坚持认为，我们无法优先了解我们的意思是什么，甚至无法优先了解我们的意思是否有意思，这也是正确的。黑格和德里达坚持认为，只有对解释的解释，以及进一步的解释，没有充分理由称其中的任何一个为绝对真理，这也是正确的。所以，我们将不得不与科学一起，接受真理的“素食主义”概念，这个概念可以揭示人类得以往返月球的真实原因，从而引领人类探索星际。

**结语 如果我错了呢**

* “外包”式理解是个真实的现象，但你必须让自己进入一个交流社区，能够有效汇集相关的专家意见。
* “如果我错了呢？”我有一些并非万无一失的建议：鼓起勇气，着手写下这个伟大的发现。经过数小时的热烈思考和写作，如果你发现了致命的缺陷，一些被你忽略或低估的东西，别沮丧，你并没有白费努力。回到第一段，写一些类似这样的话：“这样想很诱人……因为似乎有一个强有力的论点能表明……但正如我们将会看到的，这是一个错误。”然后微调一下论文的其他部分，仔细指出你差点儿犯下的错误，你就可以提交论文了。如果你的大想法能吸引你，那也很可能会吸引其他人。
* 向该领域展示这是一条要避开的死胡同，这能带来真正的贡献。
* 如果没人可以马上推翻它，那就放胆尝试，投入大量时间，并抱有乐观的态度。而且要记住，如果你选择错了，错失机会的代价很大。你至少应该能应对一个明确的反驳，挽救你的想法，因为你是最初支持这个想法的人。

**第一部分 重磅导读**

* 丹尼特在自由意志问题上的观点被称为“相容论”(Compatibilism)。他认为，自由意志并不需要与决定论相对立，而是可以与之共存。
* 在他的著作《自由的进化》(Freedom Evolves)中，他论证自由意志是人类在复杂环境中做出选择的能力，是进化的结果。
* 他通过“饥饿的响尾蛇”实验说明：生物体通过自然选择获得预测环境的能力，这种能力在人类身上发展为道德选择机制——自由意志的本质是进化馈赠的决策复杂性。
* 我们不是宇宙的旁观者，而是自我叙事的创作者——这份创造的自由，才是进化馈赠的最珍贵礼物。
* 我们为什么需要了解丹尼特？更广泛地说，为什么在当今科学昌明、技术发达的时代，还要关心哲学？ 因为有些重大问题，科学还暂时不能、也许永远都无法给出答案，而我们迫切地想要知道答案。哲学的作用是让我们不至于完全束手无策：只要你能清晰思考，你就能得到比不思考好得多的答案。
* 意识其实是无数个微故事被随时撰写、忽略、重写和突显的过程。这里根本不需要什么小人儿来统领。而所谓“自我”，只不过是我们为整合经历而构造的叙事引力中心。
